# 安全说明

## 不保存的数据

- 用户粘贴的原始文本。
- 检测后的明文实体列表。
- AI 回复和恢复后的文本。
- 保险箱密码。

这些值只存在于一次 HTTP 请求内存或当前浏览器页面内存。服务器访问日志主动删除查询参数，也不记录请求正文。

## 会保存的数据

- 可选 OPF Python 依赖。
- 可选 OpenAI Privacy Filter 模型权重。
- 不含用户文本的模型安装状态与安装日志。

## 攻击面与缓解

- 远程访问：使用 fnOS 统一网关，由 fnOS 先验证登录状态。
- 管理操作：模型安装要求网关注入管理员身份。
- CSRF：写请求要求 `application/json`；服务不开放跨域响应头。
- 路径穿越：静态资源路径在解析后必须位于固定 Web 根目录内。
- XSS：检测到的原文只通过 `textContent` 或表单 value 渲染；CSP 禁止内联/外部脚本。
- 进程隔离：服务以 fnOS package 用户运行，不使用 root，不请求额外系统权限。
- 供应链：基础 Python 由 fnOS `python312` 运行时提供；OPF 源码与模型 revision 固定。第三方 Python wheel 仍需在目标 x86_64/ARM64 设备上完成兼容性验证。
- 资源耗尽：请求正文限制为 2 MB，文本限制为 500,000 字符；模型推理由进程级锁串行执行。

## 已知限制

- fnOS 网关只保证已登录，不替代应用业务权限；当前应用不持久化用户业务数据。
- 浏览器刷新会丢失未导出的映射。
- 如果 AI 改写了占位符，无法自动恢复；界面会报告未知或缺失占位符。
- 模型对中文并非专门训练，规则引擎也无法覆盖所有行业编号和语言表达。
- 运行模型需要较多内存；低配 NAS 应只使用中文规则模式。
