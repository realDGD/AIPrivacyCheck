PRIVACY BOUNDARY

这款应用会做什么

  • 01
    中文规则始终可用

    身份证、银行卡、手机号等高敏字段优先使用格式与校验位识别。

  • 02
    模型只接收本地文本

    模型权重从 Hugging Face 下载；检测时不会调用 Hugging Face 或 OpenAI API。

  • 03
    不会承诺 100% 漏检率

    姓名、地址和专业领域标识符可能漏检或误检，发送前必须人工复核。

  • 04
    不保存原文与回复

    服务不建立文本数据库、不记录请求正文；刷新页面会丢失当前映射。
